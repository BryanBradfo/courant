Courant

Cozy reminders for developers to drink water, rest your eyes, and stretch.

pipx install courant
View on GitHub →

Free, open-source, Linux-first.

Built for focus, not interruption

Gentle nudges

Configurable intervals between 09:00 and 18:00 by default, weekdays only. Never during deep work.

Beautiful by design

Ambient video scenes, lofi music, glassmorphism UI. Inspired by studywithme.io. Your reminder dashboard you actually want to look at.

Local-first privacy

Runs entirely on your machine. No accounts, no cloud, no telemetry. Your habits stay yours.

Get started in 30 seconds

pipx install courant
courant start
open http://localhost:8765

Then it runs in the background. The web UI is at localhost:8765 ready when you need it.

Or set up auto-start with systemd →

Everything in the box

Six ambient scenes

Cozy cabin, retro moon, night train, cat sunrise, cat in the rain, lofi study.

Six lofi music tracks

Cozy night, mellow, study, focus, daydream, jazzy.

Customizable intervals

Water, eye breaks, stretching, or whatever you need.

Daily auto-reset

Counters reset at midnight automatically.

D-Bus notifications

Native Linux desktop notifications with snooze and +1 actions.

systemd integration

Auto-starts on login as a user service.
